# 🧑‍💻 PROVA PRÁTICA — DESENVOLVIMENTO DE SISTEMA JAVA

> **Tipo:** Trabalho prático + apresentação (**5 pontos + 3 pontos**)  
> **Valor:** **8,0 pontos**  
> **Entrega:** Projeto completo + apresentação

**Modalidade:** Individual, duplas ou trios.

---

## 🎯 1. OBJETIVO

Desenvolver um sistema para realizar o **cadastro e gerenciamento de animais disponíveis para adoção**.

O sistema deverá permitir que consiga **cadastrar, consultar, atualizar e excluir** animais.

O objetivo da atividade é colocar em prática os conhecimentos de **Java, Spring Boot, programação orientada a objetos e desenvolvimento de API REST**.

---

## 📌 O sistema deverá possuir:

### 1. Java
O projeto deverá ser desenvolvido utilizando **Java**.

### 2. IntelliJ IDEA
O desenvolvimento deverá ser realizado no **IntelliJ IDEA**.

### 3. Spring Boot
O sistema deverá utilizar **Spring Boot** para criação da aplicação.

### 4. API REST
O projeto deverá possuir **endpoints** para realizar operações no sistema.

---

## 🎬 Durante a apresentação, deverão demonstrar pelo menos:

- [ ] Cadastro de um animal
- [ ] Consulta dos animais
- [ ] Consulta de um animal pelo ID
- [ ] Alteração de um animal
- [ ] Exclusão de um animal
